# ¿Soy sujeto de crédito? Ecuador

Proyecto web que ayuda a una persona a evaluar si es **sujeto de crédito** en Ecuador.

## Contenido

- `index.html`: página estática **autocontenida** (estilos y scripts incluidos en el mismo archivo, sin dependencias externas ni servidor).

## Cómo usarlo

Abre `index.html` con doble clic en cualquier navegador moderno.

## Cómo publicarlo con GitHub Pages

1. En GitHub: **Settings → Pages**.
2. En *Source* elige la rama que contiene `index.html` y la carpeta `/ (root)`.
3. Guarda; el sitio quedará disponible en `https://<usuario>.github.io/Sujeto-de-credito-/`.
